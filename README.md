# NexGen Education — Diploma in Human Resource Management

A responsive redesign of the [existing NexGen course page](https://nexgen.lk/diploma-in-human-resource-management/), built with plain HTML and CSS. Open `index.html` in a browser, or serve this folder with any static host. There is no build step, backend, or external asset dependency.

The supplied course brief is the source for the proposed 3-month duration, 12 modules, schedule and delivery options, and career pathways. The existing live page lists different course details; NexGen should verify the proposed copy and admissions requirements before replacing the live page. Fees and credits were not supplied and are referred to admissions. Enquiry links use NexGen’s existing contact channels and do not collect data on this page.

The logo and the original course photograph (Mikhail Nilov / Pexels) were sourced from the NexGen site. Page styles and colour variables live in `styles.css`.
