# NexGen Education — Diploma in Human Resource Management

A responsive redesign of the [existing NexGen course page](https://nexgen.lk/diploma-in-human-resource-management/), built with plain HTML and CSS. The layout follows the supplied course-page reference, with a split banner, programme fact cards, paired course sections and a dedicated admissions panel. Open `index.html` in a browser, or serve this folder with any static host. There is no build step, backend, or external asset dependency.

The Diploma in HRM tab of Website Details (2).xlsx is the source for the proposed 3-month duration, 12 modules, schedule and delivery options, entry requirements, learning objectives, target audience, and career pathways. The existing live page lists different course details; NexGen should verify the proposed copy before replacing the live page. The brief leaves the awarding body blank and lists fees and credits as N/A. The page displays fees and credits as N/A and refers awarding body questions to NexGen admissions. The programme outline uses the 12 supplied module titles with short topic summaries. The application popup submits enquiries to NexGen’s existing contact form service.

The logo and the original course photograph (Mikhail Nilov / Pexels) were sourced from the NexGen site. Page styles and colour variables live in `styles.css`. Poppins is bundled locally under the SIL Open Font License (see `assets/fonts/OFL-Poppins.txt`).
